# Emploi du temps en tableau — Laravel + app mobile Expo + publicité

Ce planning est adapté à ton projet actuel :

- **Site web** : Laravel e-commerce.
- **Backend mobile** : API Laravel `/api/...` avec authentification Sanctum.
- **Application mobile** : React Native / Expo dans le dossier `mobile/`.
- **Marché cible** : Mali / Bamako / FCFA.

Objectif : mettre en place le site, l’application et la pub sans se disperser.

## 3. Priorités techniques en tableau

| Priorité | Partie | Action | Pourquoi |
|---:|---|---|---|
| 1 | Site | Accueil clair : livraison Bamako/Mali, paiement, produits phares | Le client comprend vite |
| 2 | API | Vérifier `/api/products`, `/api/categories`, `/api/login`, `/api/cart` | L’app dépend de l’API |
| 3 | App | Vérifier `mobile/src/config.js` avec la bonne URL API production | Éviter “Network Error” |
| 4 | Produits | Remplacer produits fictifs par produits réels | Crédibilité |
| 5 | WhatsApp | Bouton WhatsApp visible sur site et app | Commande rapide au Mali |
| 6 | Paiement | Afficher paiement à la livraison + mobile money disponible | Rassurer client |
| 7 | Livraison | Expliquer zones, délais et frais | Réduire questions |
| 8 | App | Tester sur téléphone réel Android | C’est là que tes clients seront |
| 9 | Sécurité | Ne jamais mettre identifiants MySQL dans l’app | Protection données |
| 10 | Mesure | Suivre messages, commandes, produits gagnants | Décider avec les chiffres |
